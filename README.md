# ⛽ Gas Retail Ordering App

WhatsApp ordering + inventory tracking system for Gas Retail Business in Enugu.

### Features
- View gas products with live stock
- Order form with name, phone, address
- Auto stock deduction
- WhatsApp integration — order goes straight to seller's WhatsApp

### Tech
Python, Flask, HTML

### How to Run
```bash
pip install flask
python app.py
# Open http://127.0.0.1:5000
